BTMATH.ELF — third-party software notices
===========================================

The BTMATH.ELF guest binary (built by tools/go/build-btmath.sh)
statically links the following third-party Go modules. Their sources are NOT vendored in this
repository: they resolve into the host Go module cache at build time
and are overlaid, never copied in-tree. This file carries the
copyright and permission notices their licenses require for binary
redistribution.

Pinned versions below match `VERSION=`/`BUBBLES_VERSION=` in
tools/go/build-btmath.sh plus MVS resolution at the time of writing
(`go list -deps` over the btmath import closure — Bubble Tea plus the
Bubbles textinput/help/progress/key/cursor packages and their lipgloss
v2 closure). Bumping either version requires re-resolving and updating
this file; the build script fails if a pinned version string is absent
here.
