GOSSHD.ELF — third-party software notices
===========================================

The GOSSHD.ELF guest binary (built by tools/go/build-sshd.sh)
statically links the following third-party Go modules. Their sources are NOT vendored in this
repository: they resolve into the host Go module cache at build time
and are overlaid, never copied in-tree. This file carries the
copyright and permission notices their licenses require for binary
redistribution.

Pinned versions below match `VERSION=` in tools/go/build-sshd.sh
plus MVS resolution at the time of writing (`go list -deps` over the
sshd import closure, which is Bubble Tea only — the same closure as
BTMATH.ELF, no lipgloss). Bumping the Bubble Tea version requires
re-resolving and updating this file; the build script fails if the
pinned version string is absent here.
