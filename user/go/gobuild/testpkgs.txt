# testpkgs.txt -- M112b (#2414): the pinned in-guest test package list.
#
# Run rows are bare package source dirs under the test root (/host/SRC):
# GOBUILD compiles the package's test variant + external test package +
# generated testmain into T_<mangled>.ELF, execs it with -test.v, and reads
# the verdict out of the captured stream. `excluded <pkg> <reason>` rows are
# pinned non-participants — every user/go package with _test.go files that
# is NOT run in-guest appears here with its named reason (the card: "each
# excluded package is named with its reason"), never silently skipped.
#
# Exclusion reasons observed/verified:
#   needs_asm:          virelai-tagged .s gateways need cmd/asm, which the
#                       in-guest toolchain does not ship (ADR 0035 D4)
#   dep_unsupported:    the package's test closure needs a standard package
#                       the M107b table does not stage (first missing dep
#                       named in the reason)
#   host_fixture:       tests read host-repo paths (../../../...) that do
#                       not exist on the share
#   host_env:           tests assert the host's ENOSYS stub semantics where
#                       the guest's real channel answers differently
#   guest_enosys:       tests need a syscall the guest channel does not
#                       implement
#   module_closure:     tests transit into the pinned Charm/module tree
#                       that is staged only for the fleet build rows
