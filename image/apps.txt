# VirelaiOS app manifest, schema v2 (M82a #1768). Shipping EL0 apps only; the
# Go seat's daily set is docked. TABWM.BIN is the Zig fallback (ADR 0034).
#
#   NAME | Display Name | icon | dock=true | v=2 | argv= | caps= | opens=
#
# Fields 1-4 are the v1 shape every reader parses. Trailing key=value fields
# are ADDITIVE: order-insensitive, unknown keys ignored; a v1 reader that
# stops at field 4 is not wrong. No `v=` means v1, no trailing fields.
#   v=     schema version; only a v2 row is asked for the rest. A tailed row
#          MUST carry all four positional fields — field 4 is the dock flag
#          in every reader, so an undocked v2 row writes `dock=false`.
#   argv=  fixed arguments after the binary, space separated, at most 8 (the
#          kernel's exec bound). v1: none.
#   caps=  declared capabilities, comma separated (WASM Cap names;
#          user/src/wasm.zig). Enforced narrow-only at exec: grant
#          decision ∩ (declared ∪ {memory,process,debug}); `caps_denied`
#          names the refusal. No caps= → unenforced. (ADR 0054, #3186)
#   opens= what the app can be handed: an M81b mime type (text image audio
#          archive binary document), a URL scheme (http https; M81c #1763),
#          or an M124a (#2580) type/subtype spelling (text/plain, image/png).
#          A bare family word takes any subtype on the drag hit-test; a
#          subtype spelling takes only itself.
#   selection=  M124e (#2584): `primary` opts into the seat's primary
#          selection — publish on select, deliver on middle-click or
#          shift+insert. A REAL gate: no word, no publish, no delivery.
#
# BUDGET: every reader buffers 4096 B (sexiburger.manifest_buf_max — carried
# by wnd.zig, tabwm.zig and the Go seat's appsMaxBytes). A file at or over
# that is truncated at the last whole line, silently dropping tail rows.
# sexiburger's host test pins this file under it. A not-yet-shipped row
# refuses "Binary not staged".
# Registry: each row needs an `app` row in docs/component-registry.md.
