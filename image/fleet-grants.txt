# Fleet grant policy — M116a (#2467), ADR 0054 Part II base rows.
#
# One line per shipped app:
#
#   NAME <TAB> OBSERVED <TAB> MASK <TAB> REASON
#
#   NAME      the exec-recorded image name (a GRANTS.TXT row key).
#   OBSERVED  the words the app called under the M113f audit (#2422,
#             comment-6243607948: 29 apps, one confined `NAME<TAB>*<TAB>-`
#             boot each, `audit:<word>_denied` receipts = calls made), or
#             `-` when the audit could not run it.
#   MASK      the authored grant word set, in vocabulary order
#             (file window audio timer memory process debug net term).
#   REASON    `-` when MASK == OBSERVED; otherwise the named reason the
#             mask is wider than observed — the card's rule is mask ⊇
#             observed and never wider without a named reason.
#
# Every row is `*`-bound (name-only, narrow-only): these become compiled
# base rows (kernel/src/grant_fleet.zig, GENERATED — do not hand-edit;
# regenerate with `python3 tools/grants/fleet_grants.py emit`), verified
# by the Part I boot chain — a different table is a different KERNEL.BIN
# digest. Wildcard is the audit data's own suggested shape; a `*` row can
# only narrow, so a renamed binary can only lose power, never gain.
#
# Provenance key for REASON: "audit note" cites the M113f table's own
# notes; "declared" cites the app's apps.txt caps=/opens= contract;
# "surface" cites vi.*/sys_* call sites in the app's source for paths the
# 35 s audit window could not reach.
